# Snake Game

Классическая игра "Змейка", написанная на Go с графикой через [Ebitengine](https://github.com/hajimehoshi/ebiten).

## Особенности

- 🐍 Адаптивное игровое поле (подстраивается под размер окна)
- 🎨 Круглые сегменты змейки с градиентом и подсветкой
- 👀 Глаза со зрачками, следующие за направлением движения
- 🍎 Пульсирующее яблоко с glow-эффектом, стеблем и листиком
- ✨ Система частиц при поедании еды
- 🎮 Очередь направлений для быстрых нажатий клавиш
- 🎮 Управление стрелками или WASD
- 📈 Увеличение скорости с каждой съеденной едой
- 🏆 Система рейтинга (Beginner → Legend)
- 🖥️ Стилизованная панель HUD с flash-эффектом при счёте
- ✅ 20 unit-тестов

## Установка

### Требования

- Go 1.25+

### Сборка

```bash
git clone https://github.com/ak70188954/snake-game.git
cd snake-game
go build -o snake-game .
./snake-game
```

### Запуск

```bash
go run .
```

## Управление

| Клавиша        | Действие           |
|----------------|--------------------|
| ↑ / W          | Движение вверх     |
| ↓ / S          | Движение вниз      |
| ← / A          | Движение влево     |
| → / D          | Движение вправо    |
| Space / Enter  | Начать игру        |

## Архитектура

### Логика (snake.go)

- `Snake` — основная структура с телом, направлением, скоростью и очередью
- `Direction` — тип направления (Up, Down, Left, Right)
- `GameMode` — состояние игры (Menu, Playing, GameOver)
- `SetDirection()` — устанавливает направление напрямую (для тестов)
- `QueueDirection()` — добавляет направление в очередь (для игрового ввода)
- `WasEaten()` — возвращает true если еда съедена в этом кадре
- `Update()` — игровой цикл логики (движение, коллизии, поедание)

### Графика (main.go)

- `Game` — структура с рендерингом и системой частиц
- `calculateLayout()` — адаптивный размер клетки
- `drawGrid()` — тёмное шахматное поле с синей светящейся рамкой
- `drawSnake()` — круглые сегменты с градиентом, подсветкой, глаза со зрачками
- `drawFood()` — пульсирующее яблоко с glow-эффектом
- `drawParticles()` — система частиц при поедании (20 частиц, разлёт по кругу)
- `drawHUD()` — стилизованная панель с flash-эффектом
- `drawMenu()` / `drawGameOver()` — экраны меню с анимацией
